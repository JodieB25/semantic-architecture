# EA-T01–EA-T04 Normalised Experience Models

This package contains table-led, structurally normalised Experience Model Prototype Slices for EA-T01 through EA-T04, a revised Experience Model Standard, and a consistency report.

The source semantics have been preserved. Where a source artefact was incomplete, the normalised version expands presentation only from the supplied journey, compiler behaviour, canonical outputs and established upstream/downstream boundaries.
