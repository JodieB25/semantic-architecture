# EA-T01 Prototype Development Package

## Purpose

This package provides the artefacts required to implement the bounded EA-T01 prototype.

The semantic production package remains the semantic authority. This package projects that authority into prototype development artefacts.

## Artefacts

| Artefact | Purpose |
|---|---|
| 09 Experience Model | Defines what the enterprise experiences. |
| 10 Prototype Interaction Specification | Defines the interaction capability required. |
| 11 Compiler Behaviour Specification | Defines deterministic compiler behaviour. |
| 12 Prototype Content Pack | Provides governed prototype content and scenarios. |

## Supported Prototype Scenarios

- TS-001 — Conveyancing Practice
- TS-002 — Real Estate Agency

## Guiding Principle

The prototype demonstrates semantic engineering, not application design. UX owns presentation. The compiler owns semantic state. The enterprise confirms understanding.
