# Glossary

| Term | Meaning |
|---|---|
| Semantic Object | A governed architectural responsibility that answers one canonical semantic question. |
| Knowledge Family | A coherent grouping of Knowledge Units. |
| Knowledge Unit | The smallest governed semantic knowledge element in a package. |
| Applicability | A governed determination of whether knowledge belongs to the resolved semantic branch. |
| Information Contract | The participation and completeness contract for semantic compilation. |
| Acquisition State | The semantic maturity of acquired information before compilation. |
| Semantic Compilation | Deterministic transformation of governed knowledge into a canonical semantic object. |
| Canonical Output | The governed semantic object produced by successful compilation. |
| Enterprise Subject | The canonical output of EA-T01. |
